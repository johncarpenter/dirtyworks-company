# Repository system

This folder governs how the company repository is organized and interpreted.

- `documentation-policy.md` defines authority, metadata, naming and lifecycle rules.
- `document-template.md` is the default Markdown scaffold.
- `systems-and-repositories-register.md` indexes other authoritative systems without copying their records here.
- `registers/` contains company-wide decision, assumption, risk, obligation, blocker and change state.
