# Company registers

Registers expose current cross-company state without requiring readers to reconstruct it from narrative documents.

- `decision-register.md` — approved and working decisions.
- `assumption-register.md` — unverified beliefs, tests and expiry dates.
- `risk-register.md` — material company risks and controls.
- `obligation-register.md` — contractual, legal, regulatory and internal obligations.
- `blocker-register.md` — work that cannot responsibly continue.
- `change-register.md` — material changes to company authority, systems or operating design.

Narrative logs may explain the story, but these registers are the authoritative current indexes.
