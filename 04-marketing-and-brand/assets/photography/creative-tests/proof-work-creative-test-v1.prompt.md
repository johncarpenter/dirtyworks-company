# PROOF / WORK photography creative test v1

**Date:** 2026-08-26  
**Mode:** Built-in image generation  
**Reference image:** `proof-work-moodboard-v1.png` — style, palette, texture, and art-direction reference only

## Set logic

The test moves from the lowest-risk bridge to the current site to the most visibly art-directed expression of the `PROOF / WORK` territory:

1. `proof-work-operator-hero-v1.png` — people-led hero with a large copy field.
2. `proof-work-hands-review-v1.png` — reusable close crop of checking and annotation.
3. `proof-work-evidence-tray-v1.png` — people-free evidence still life, closest to the moodboard.
4. `proof-work-team-review-v1.png` — dense documentary team scene with a printed-proof edge.

`proof-work-creative-test-contact-sheet-v1.png` is a 2 × 2 comparison sheet in the same order.
