# Opportunity qualification scorecard

**Purpose:** decide whether to propose a paid Knowledge Reliability Review.  
**Rule:** judgment is explicit; the number is not automatic approval.

## Scoring

Score each dimension 0–2 using observed evidence.

| Dimension | 0 | 1 | 2 | Evidence |
|---|---|---|---|---|
| Repeated event | Abstract or hypothetical | One event or weak frequency | Recent event plus recurring pattern | |
| Economic consequence | No meaningful effect | Plausible time/friction | Measurable delay, rework, revenue, continuity, or risk | |
| Existing knowledge | Mostly undocumented | Mixed source quality | Useful approved sources exist | |
| Bounded first domain | Company-wide or unclear | Possible boundary | One role group and answer domain are clear | |
| Executive sponsor | None | Interested observer | Accountable leader will sponsor | |
| Knowledge owner | None | Possible candidate | Named and available to approve sources | |
| Access and risk | Prohibited/high and uncontrolled | Remediation required | Acceptable bounded data and permissions | |
| Timing and budget | No priority or funding | Later/uncertain | Can fund a review now | |
| Total | | | | /16 |

## Decision guidance

- **12–16 and no critical zero:** propose a paid review.
- **9–11:** nurture or resolve the weakest dimension before proposing.
- **0–8:** do not pursue now.
- **Any zero in sponsor, knowledge owner, or access/risk:** no proposal until resolved.

## Fit modifiers

These do not replace the score:

**Positive:** 20–150 employees; multiple crews/locations; Microsoft 365 or Google Workspace; growth/change trigger; repeated onboarding; office/field handoff; willing to measure a baseline.

**Negative:** wants a public bot; expects perfect answers; requires undocumented knowledge to appear automatically; refuses source ownership; wants unlimited development; high-impact automated decisions; cannot justify the recurring price.

## Review recommendation

Complete after scoring:

- proposed answer domain;
- participating role group;
- up to three candidate sources;
- likely baseline measure;
- explicit excluded/high-risk questions;
- sponsor and knowledge owner;
- review price and timing;
- largest uncertainty the paid review must resolve;
- reason to proceed now;
- reason Dirty Works might still decline after the review.
